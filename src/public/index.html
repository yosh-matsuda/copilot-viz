      SSH hosts

      Uses the SSH configuration on , where copilot-viz runs, not the browser's machine. Keys and passwords stay outside this app.

      Before adding a host
      1. Configure SSH on the machine running copilot-viz. For WSL, use the SSH configuration inside WSL.
      2. Run ssh build-server in a terminal. Verify the host fingerprint before accepting it, and unlock your key through ssh-agent if needed.
      3. Verify ssh -o BatchMode=yes -o StrictHostKeyChecking=yes -o ControlMaster=no -o ControlPath=none build-server 'node --version' succeeds without a prompt and reports Node.js 22 or later.
      4. Enter that same host name below. Use Check connection, then Save and apply. The worker is installed automatically when connecting.

      The check tests SSH, Node.js, and access to the session directory. It does not install the worker or read session logs. An offline host can still be saved.

      Up to 32 hosts. Removing a host disconnects it after saving; it does not delete its logs or cached worker.
